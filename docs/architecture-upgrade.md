# 2026-10 架构与功能升级

实施顺序：先稳定共用弹窗，再开放机场资料浏览，最后统一二维 / 三维空间分析。

## 模块职责

| 模块 | 唯一职责 |
| --- | --- |
| `Home.vue` | 选择状态、工具开关、轨迹请求及分析参数编排 |
| `FloatingPanel.vue` | 标题栏、独立滚动、收起 / 关闭、拖动 / 缩放和地图内边界约束 |
| `panelGeometry.js` / `panelStack.js` | 可测试的尺寸计算 / 同一地图内面板层级 |
| `AirportBrowserPanel.vue` / `airportCatalog.js` | 机场检索、筛选、分页、详情和地理数据导出 |
| `spatialAnalysis.js` | 分等级最近邻、半径、有限球面轨迹段走廊、水平距离和高度差 |
| `mapSelection.js` | 二维 / 三维共用的选中飞机及分析对象显示规则 |
| `Leaflet_Map.vue` / `Cesium_Map.vue` | 渲染既有结果、地图控制与用户事件，不重复计算查询 |
| `useFlightData.js` / `flightApi.js` | 数据读取、静态机场缓存、刷新保护、可取消请求 |
| Django `flight_api/views.py` | GeoJSON 与机场元数据输出、可选择时间参考的归档轨迹查询 |

全局样式仅保留页面基础样式，不再从多个文件覆盖弹窗高度。弹窗没有 `!important` 规则。地图独立层叠上下文，面板置于地图控件上方；点击面板将其前置。

桌面保留可读的默认大小并允许用户调整，始终限制在地图容器内。手机面板宽度随地图变化，分析和航班列表高度为地图可用高度的 44%，机场资料库为 55%；短屏保留基本操作高度并受容器上限约束。选择飞机只改变滚动区内容，不能撑大面板。手机同一时间仅开启一个工具面板。

机场一次加载成功后缓存到页面状态，定时刷新仅查询本地航班 API。不新增远程采集频率，不消耗额外 OpenSky 请求。

## 数据事实与限制

- 当前本地数据库：11,434 个机场、55 架飞机当前记录、955 个轨迹点。
- 其中 5 架飞机有 181 点的演示轨迹；另 50 架只有单点记录。不能将演示轨迹称作真实 OpenSky 航迹，也不能把单点补造成连续轨迹。
- 本轮验证归档 API 对一条已有 181 点轨迹可以正常返回，不因记录日期过旧而为空。
- 机场原始提供方、更新时间未完整记录；界面诚实显示缺失值。机场标识不一定等于 ICAO 代码。
- 导出保留原始元数据，跳过无效坐标。查询结果导出含水平距离、可用时的高度差及查询几何。
- 分析用于资料浏览和学习，不是航空导航、碰撞预警或空域许可判断工具。

## 尚需浏览器验收

1. 在 390 × 844、手机横屏和 1440 × 900 桌面窗口分别打开三种面板，选择飞机前后高度不变，正文可滚动，关闭按钮始终可见。
2. 拖动 / 缩放桌面面板，缩小浏览器窗口，检查没有移出地图边缘；多个面板重叠时点击能前置。
3. 分析切到半径或走廊后关闭再打开，重新选择飞机，控制项与结果正常更新。
4. 二维和三维开启分析：保留匹配飞机和机场；隐藏结果或关闭分析：只显示选中飞机；点击空白取消后恢复普通显示。
5. 浏览机场，按名称 / 代码、国家、类别筛选，翻页、打开详情、反复点击定位，再导出全部筛选结果。
6. 三维检查模型、历史轨迹和连接两端高度、机场分级显示、地形 / 建筑异步加载中途关闭后的状态。
7. 检查尺子测距、鹰眼隐藏 / 显示和全屏时面板层级。外部天气、瓦片、Cesium ion 加载依赖网络及有效凭据，需分别验收。

完成上述验收再提交推送；Render 自动部署后复查前后端连接。
